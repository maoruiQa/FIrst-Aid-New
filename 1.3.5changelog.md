# First Aid New 1.3.5

Configurable knockdown rules, with a full-screen notice so every player knows how the server handles a collapsed head or body.

Applies to all seven maintained builds: Forge 1.20.1, Fabric and NeoForge 1.21.1, 26.2, and 26.3. Minecraft 26.1 and 1.21.11 modules remain legacy-only and are excluded.

## Knockdown mode

- Added a server knockdown mode that decides what happens when the head or body reaches 0 HP:
  - `always`: the player is always downed instead of dying (the previous behaviour).
  - `chance` (default): the damage beyond what the critical part had left (overflow, after armor) decides between downed and death.
  - `never`: there is no downed stage; the player dies immediately.
- In `chance` mode the downed chance is `exp(-k × overflow / part max health)`. The default coefficient `k = 0.35` favours going down: a hit that exactly empties the part always downs, one part-max of overflow downs 70% of the time, two part-maxes 50%, three 35%, and five 17%.

  | Overflow / part max HP | 0 | 0.5 | 1 | 2 | 3 | 5 |
  |---|---|---|---|---|---|---|
  | Downed chance (k = 0.35) | 100% | 84% | 70% | 50% | 35% | 17% |

  `k = 0` behaves like `always`; higher values (up to 5) make heavy overkill hits lethal more often. Because the overflow is measured against the part's maximum health, the curve stays meaningful after `/firstaid health` changes.
- Unchanged in every mode: losing the head and the body at once is always fatal, a Totem of Undying is still consumed before death, and players who are already down are not affected by a mode change. With PlayerRevive installed, its own bleed-out handling still applies on the death path.

## Administrator controls

- `/firstaid knockdown` shows the current mode, the coefficient, and sample chances.
- `/firstaid knockdown always|chance|never` switches the mode; `/firstaid knockdown coefficient <0-5>` sets the coefficient. Both require operator permission, save immediately, and notify online players. Changing the coefficient outside `chance` mode is saved but does not show a notice.
- New server config keys under Command Settings: `knockdownMode` (`always` / `chance` / `never`) and `knockdownOverflowCoefficient` (0–5, default 0.35). They live in the same server config as the other First Aid settings (`config/firstaid-server.toml` on NeoForge and Forge, `config/firstaid/firstaid-server.json` on Fabric); edits to the file apply on the next server start.
- `/firstaid reset` restores `chance` with `k = 0.35`. The operator join tips list the new command.

## Knockdown notice

- Players see a full-screen notice describing the current knockdown rules the first time they join a world or server. In `chance` mode it also shows the coefficient and a chance table.
- After that, the notice appears again only when the rules change: immediately for players who are online when an administrator runs a command, and on the next join for players who were offline or when the config file was edited between restarts.
- The notice can only be closed with its "I understand" button (Escape does not dismiss it) and does not pause the game. It waits for loading and death screens to finish, re-opens if another screen replaces it before it is confirmed, and a newer change replaces an open notice instead of stacking.
- Acknowledgements are stored per world in `firstaid/knockdown_notice.json` (player UUID and the acknowledged settings), so they survive deaths and restarts. A player who leaves without confirming sees the notice again on the next join.
- Forge's network protocol is now `7.1` because of the new notice packet; use matching First Aid versions on the client and server.

## Builds and checks

- Published `1.3.5+<loader><minecraft-version>` installable mod JARs for the seven maintained modules in `release/`. Source and development JARs are excluded.
- Added `tools/check_knockdown_mode.py`: compiles the production knockdown code of every module against stubs and checks the formula, overflow tracking, every mode decision, totem order, commands and permissions with real Brigadier, acknowledgement storage, and translations.
- Added `tools/check_knockdown_runtime.py` with `tools/KnockdownRuntimeProbe.java`: launches real dev servers and clients for each module and drives the notice, every mode, coefficient extremes, dedicated-server console changes for online and offline players, and config-file edits.
- Added `KnockdownModeGameTests` to the NeoForge 26.3 GameTest suite.
