# First Aid New 1.3.6

Server controls for combat adrenaline, so horde-heavy modpacks no longer push every fight to tier V.

Applies to all seven maintained builds: Forge 1.20.1, Fabric and NeoForge 1.21.1, 26.2, and 26.3. Minecraft 26.1 and 1.21.11 modules remain legacy-only and are excluded.

## Combat adrenaline limits

- Added `adrenalineMaxLevel` (0–5, default 5): the highest tier that hits, projectile near misses and nearby enemies can build. Pressure stops just below the next tier, so the effects, injury relief and visuals all stay at the chosen level. `0` keeps combat below tier I. Adrenaline and morphine injectors still reach full strength. Combat never lowers pressure that is already above the cap, but it no longer holds it there either, so injector pressure decays back to the cap on schedule even while the player keeps fighting.
- Added `adrenalineAttackGainMultiplier` (0–2, default 1): scales the adrenaline gained from hitting enemies, on top of the existing global `suppressionGainMultiplier`. `0` disables hit-driven adrenaline without affecting near misses or encounters, and no longer refreshes the hold timer.
- Added `adrenalineAttackCooldownTicks` (0–200, default 0): minimum ticks between counted hits per player, for fast weapons such as modded guns.
- Added `adrenalineAttackHoldTicks` (0–200, default 40): how long adrenaline holds after a hit before it decays. Previously fixed at 40 ticks.
- Hits that land in the same tick now count as one attack. A sweep that hit four mobs used to add four gains; it now adds one. In the runtime check, sweeping four husks every 0.6 seconds reaches tier V after 13.2 seconds instead of about 3, and with `maxlevel 2` plus `attackgain 0.5` it settles at tier II after 3.6 seconds. Single-target combat is unchanged with the default settings.
- Commands (operator only, saved immediately): `/firstaid adrenaline maxlevel <0-5>`, `attackgain <0-2>`, `attackcooldown <ticks>` and `attackhold <ticks>`; the legacy `/firstaid suppression` alias has them too. `/firstaid reset` restores the defaults.
- Clarified the config comments: `suppressionGainMultiplier` is the global gain for hits and near misses, and `encounterBaseIntensity` only sets the passive level from seeing hostiles. It does not affect hit gain.
- Suggested preset for horde-heavy packs: `/firstaid adrenaline maxlevel 2`, `attackgain 0.5`, `attackcooldown 10`.

## Fixes

- Forge 1.20.1: projectile near misses add adrenaline again. The default near-miss path had been emptied in 1.3.4, so arrows flying past Forge players never raised pressure, unlike the other loaders.

## Builds and checks

- Published `1.3.6+<loader><minecraft-version>` installable mod JARs for the seven maintained modules in `release/`. Source and development JARs are excluded. No network protocol change; 1.3.5 and 1.3.6 differ only on the server side.
- Added `tools/check_adrenaline_limits.py`: compiles the production adrenaline code of every module against stubs and checks the tier cap for hits, near misses and encounters, same-tick merging, the cooldown, the multiplier, config keys, commands and translations.
- Added `tools/check_adrenaline_runtime.py` with `tools/AdrenalineRuntimeProbe.java`: launches a real dev client per module and drives every new command, real hits on husks through each loader's damage events, the injector above the cap, config persistence, `/firstaid reset`, and two 25-second horde fights with screenshots.
- Extended the NeoForge 26.3 `SuppressionRegressionGameTests` with the cap, multiplier, same-tick and injector cases.
