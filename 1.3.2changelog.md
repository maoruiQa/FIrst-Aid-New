# First Aid New 1.3.2

Applies to the maintained Forge 1.20.1, Fabric and NeoForge 1.21.1, 26.1, 26.2, and 26.3 modules. The 1.21.11 legacy modules remain unchanged.

## Medicine and crafting

The following changes apply to Forge 1.20.1 and Fabric/NeoForge 1.21.1, 26.2, and 26.3. The 26.1 and legacy modules keep their existing behavior.

- Added administrator commands to query or set `/firstaid addiction gain <morphine|morphine_injector> [value]` (0–100), `/firstaid crafting yield <bandage|plaster|painkillers|morphine> [count]` (1–16), and `/firstaid crafting durability <morphine_injector|adrenaline_injector|defibrillator> [uses]` (1–1000). Omitting the value queries the current setting. Crafting changes persist and reload/sync recipes automatically; failed reloads restore the previous setting.
- Raised the default addiction gain per use to 7.8 for oral Morphine and 20 for the Morphine Injector. Existing medical-use multipliers and the addiction cap are unchanged; saved administrator settings are not overwritten.
- Shortened the Morphine Injector's regeneration effect from 3600 to 2520 ticks (70%) and its new Morphine and pain-relief effect durations to 85% of their previous values. Updated its tooltip duration range.
- Doubled the default Bandage and Plaster recipe yields from 2 to 4; Painkillers remain 2 and Morphine remains 1. Newly crafted Morphine/Adrenaline Injectors default to 2 uses and Defibrillators to 3. Durability settings apply to newly crafted items only, not existing items or items from other sources.
- Adjusted results after datapack recipes are loaded, retaining overridden ingredients, recipe shape, and other result data. Unstackable devices still craft one at a time.

## Fixed

- Restored the Morphine Injector crafting recipe on Fabric and NeoForge 26.2 by using the ingredient format required by that Minecraft version. The recipe still requires two Morphine, iron, redstone, and a glass bottle.
- Fixed recipe result customization on the 26.2/26.3 modules so recipe loading does not create item stacks before item components are bound; NeoForge 1.21.1/26.x now tolerates recipe loading before its server config is available.
- Audited the other maintained recipe files for missing recipes, malformed JSON, and mismatched results. No further damaged recipes were found. The 26.1 modules do not register a Morphine Injector, so they intentionally have no recipe for it.

## Version

- Set all nine maintained loader/version modules to `1.3.2+<loader><minecraft-version>`.
- The 26.1 modules keep their existing feature set; this version change does not add the Morphine Injector to 26.1.
